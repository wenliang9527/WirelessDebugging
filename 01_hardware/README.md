## 已实测的板载参数(2026-10-28,作为 PCB 设计输入)

板型:**YD-ESP32-S3**,模组 **ESP32-S3-WROOM-1-N16R8**,44 脚双 USB-C。

| 项目 | 实测值 | 对 PCB 的含义 |
| --- | --- | --- |
| 主控 | ESP32-S3 (QFN56) rev v0.2,双核 240MHz + LP 核 | 选型确认 S3,原计划 C3 对比实验可取消 |
| Flash | **16 MB**(博雅 0x68/0x4018) | 分区可自由规划,双 OTA 分区绰绰有余(不是瓶颈) |
| PSRAM | 8 MB 嵌入,**Octal SPI** 占用 GPIO35/36/37 | 当前编译未启用;PCB 若沿用同模组,**这 3 个脚不能引出他用** |
| Flash 接口 | QIO 四线 / 3.3V(eFuse 设定) | PCB 按四线布局,3.3V 供电 |
| 晶振 | 40 MHz | |
| MAC | `aa:bb:cc:dd:ee:fc` | 出厂唯一,可用作设备标识后缀(AP SSID / mDNS) |
| 原生 USB | GPIO19(D-)/20(D+) | **PCB 必须引出到 USB-C**,这是烧录 + 命令通道 |
| USB 转串口 | 板载 CH343P | **PCB 建议省掉**:产品用不到,还能避免"CH343 口插着把芯片拽进下载模式"的坑 |

### ⚠️ 指示灯:在 GPIO48,是 WS2812,不是普通 LED

上游 `wifi_handle.c:27` 定义的 `PIN_LED_WIFI_STATUS 4` **在这块板上是错的**——GPIO4 只是普通引出脚,点它没有任何灯亮。板载 RGB LED 是 **WS2812(可寻址)接 GPIO48**,必须用 RMT 外设驱动(IDF 4.4.2 自带 `led_strip` 组件)。

好消息:一颗灯可显示任意颜色,比单色灯更适合状态指示(绿=STA 正常 / 黄闪=连接中 / 蓝闪=AP 配网 / 红闪=故障)。
