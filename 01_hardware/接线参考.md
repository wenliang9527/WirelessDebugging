# 接线参考(原型验证阶段)

> GPIO 定义来自 windowsair/wireless-esp8266-dap v0.4.0 release(与仓库 README 一致)。目标芯片以 ARM Cortex-M SWD 四线起步。

## ESP32-C3(调试器)

| SWD 信号 | C3 引脚 |
| --- | --- |
| SWCLK | GPIO6 |
| SWDIO | GPIO7 |
| TVCC(电平参考) | 3V3 |
| GND | GND |

| 其他 | C3 引脚 |
| --- | --- |
| nRESET(复位目标,可选) | GPIO5 |
| nTRST(可选) | GPIO4 |
| LED(WiFi 状态) | GPIO10 |
| UART Tx(透传,默认关闭) | GPIO19 |
| UART Rx | GPIO18 |

## ESP32-S3(调试器)

| SWD 信号 | S3 引脚 |
| --- | --- |
| SWCLK | GPIO12 |
| SWDIO | GPIO11 |
| TVCC(电平参考) | 3V3 |
| GND | GND |

| 其他 | S3 引脚 |
| --- | --- |
| nRESET(可选) | GPIO13 |
| nTRST(可选) | GPIO14 |

> S3 的 LED / UART 引脚以仓库 README 为准(v0.4.0 为 S3/C3 使用了专用 GPIO,以固件实际打印为准)。

### 本项目实际板子的补充(2026-10-28 原理图核对)

上面的 C3 表是**上游默认定义**,不要直接套到这块 YD-ESP32-S3 上。本项目在 S3 上的实际取值:

| 项 | 本项目取值 | 依据 |
| --- | --- | --- |
| WiFi 状态灯 | **GPIO48**(WS2812,需 RMT) | 原理图 `U1 XL-5050RGBC-WS2812B` 的 DIN 接 GPIO48 |
| 串口桥 TX | **GPIO17**(J1-9) | 引到排针,原理图网络名就是 GPIO17 |
| 串口桥 RX | **GPIO18**(J1-10) | 引到排针,原理图网络名就是 GPIO18 |

> ⚠️ 上表 C3 栏里的"LED = GPIO10"、"UART Tx = GPIO19 / Rx = GPIO18"是 **C3 板型**的定义,**不适用**于本项目的 S3 板。S3 上 GPIO19/20 是 native USB(D−/D+),绝不能当 UART 用。

## 目标板一侧(以 STM32/PY32/AT32 类 Cortex-M 为例)

| 目标板引脚 | 接调试器 |
| --- | --- |
| SWCLK / SWCLK(PA14 等) | SWCLK |
| SWDIO / SWD(PA13 等) | SWDIO |
| VDD / 3V3 | TVCC |
| GND | GND |
| NRST(可选) | nRESET |

## 注意事项

1. **必须共地**:GND 一定要接,只接 SWCLK/SWDIO 会完全不通
2. **TVCC 接目标板 3V3**(不是 5V):用作电平参考;目标板自己供电,调试器不从目标板取电
3. **⚠️ 目标板必须是 3.3V 逻辑**:ESP32 的 GPIO **非 5V 容忍**。PY32/AT32/STM32 目标板即使 5V 供电,IO 一般也是 3.3V 逻辑——确认后再接;真 5V 逻辑的目标必须加电平转换,否则可能损坏调试器
4. **杜邦线尽量短**:SWD 高速时钟下长线会信号完整性变差(>=10MHz 时明显),20cm 以内
5. 目标板上电顺序无所谓,但调试器与目标板先各自上电、再从 PC 侧连接,成功率高
6. 若目标板 SWD 被复用禁用(如 STM32 的 SWD 引脚被配成 GPIO),需用串口/复位时序先救回——这是常见"连不上"原因,不是调试器问题
7. **nRESET(GPIO13)是可选线**:不接时复位走 SWD 软复位(SYSRESETREQ),日常调试/烧录够用;接上才有硬复位能力——救被禁用的 SWD、唤醒深度睡眠目标、完整复位外设,这三种场景才必需

## JTAG 模式(调 ESP32 / RISC-V 等 JTAG 目标时用,附加场景)

| JTAG 信号 | C3 引脚 | S3 引脚 |
| --- | --- | --- |
| TCK | GPIO6 | GPIO12 |
| TMS | GPIO7 | GPIO11 |
| TDI | GPIO9 | GPIO10 |
| TDO | GPIO8 | GPIO9 |
| nTRST(可选) | GPIO4 | GPIO14 |

> ESP32 家族目标(含 C3/S3 目标)没有 SWD,只能 JTAG;烧录 ESP32 目标固件通常仍走其串口/esptool,JTAG 主要用于在线调试。
