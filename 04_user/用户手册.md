# 无线调试器 · 用户手册

适用固件 **v0.7.0** 及以上、配网工具与固件同版本发布。目标读者:拿到板子的同事/用户,不需要懂 ESP-IDF。

---

## 1. 这块板子能干什么

把一台 CMSIS-DAP 调试探针(ARM 芯片的 SWD 下载/调试)和一路串口,通过 WiFi 变成无线的:

| 功能 | PC 侧怎么用 | 走哪个端口 |
| --- | --- | --- |
| Keil 无线下载/调试 | elaphureLink(装驱动后 Keil 里直接选) | TCP 3240 |
| OpenOCD 无线 SWD | usbip 桥接出虚拟 USB,再开 OpenOCD | TCP 3240 |
| 无线串口(看目标板日志) | 任意 TCP 客户端连 `dap.local:1234` | TCP 1234 |

板子一边插目标板的 SWD 四根线(SWCLK/SWDIO/GND/3V3)和串口两根线,一边通过 WiFi 连你家/公司的路由器。**PC 和板子必须在同一个路由器下。**

---

## 2. 认识硬件

以 YD-ESP32-S3 开发板为例,两个 USB-C 口:

| 口 | 名称 | 用途 |
| --- | --- | --- |
| 标着 **COM** 的 | native USB(USB-Serial/JTAG) | **配网、烧固件、看日志,一律插这个** |
| 标着 **USB** 的 | CH343 桥 | 平时不用;插了它再按复位会进下载模式,板子会"假死" |

状态灯(板载 WS2812,在 USB 口旁边):

| 颜色 | 含义 |
| --- | --- |
| 白色呼吸 | 启动中 |
| 黄色慢闪 | 正在连 WiFi(还没拿到 IP) |
| **绿色常亮** | 已连上 WiFi,可以干活了 |
| 蓝色慢闪 | AP 配网模式(板子自己开了热点) |
| 红色快闪 | 列表里的网络一个都连不上 |

## 3. 首次配网(3 步)

前提:PC 和板子最终要连同一个路由器;手边有一根 USB-C 线。

1. **插 USB**:USB-C 线插板子标 **COM** 的口,另一头插 PC。
2. **打开配网工具**:运行 `dap_config.py`(或打包后的 `无线调试器.exe`),工具自动探测设备并显示固件版本。
3. **选 WiFi 填密码**:在「扫描连接」页选中你家/公司的 WiFi,输入密码,点「连接选中」。连上后状态灯变绿,以后板子开机都会自动连它。

配好一次就存进板子了,以后通电自动连,**不再需要 USB 线**。

### 3.1 固定优先(📌)

「已保存网络」页每一行有一个「固定」列:

- **固定优先**:开机**永远先试这一条**,连过别的网络也不会被顶掉。适合公司/家里主网络。
- **置顶**:只是把条目挪到最前,下次手动连别的网络会被顶下去(最近使用优先)。

多台设备漫游、或板子在家/公司两个网之间搬的场景,把常用的那个「固定优先」即可。设置存在板子里,断电不丢。

### 3.2 AP 配网模式(救命通道)

WiFi 换了密码、路由器没了,板子连不上任何网络时:

- 在配网工具里点「切到 AP」;或者根本连不上时,板子会自动红/蓝灯提示。
- AP 模式下板子自己开热点:名字 `DAP-XXXX`(后四位是 MAC 尾号),密码 `12345678`。
- PC 连上这个热点,浏览器/工具访问 `192.168.4.1`。
- **AP 模式没有外网**,只用于救急改配置;改完切回 STA。

## 4. 日常使用

### 4.1 Keil 无线调试

1. 装 elaphureLink 驱动(交付包里带)。
2. Keil → Options for Target → Debug → 选 **elaphureLink Debugger**。
3. Settings 里设备地址填 `dap.local`(或板子 IP),点连接。
4. 之后下载/单步/看变量与有线一致。

### 4.2 OpenOCD 无线烧录(AT32 等)

1. 「调试接入」页先点 usbip 卡片的「挂载」(要管理员权限,UAC 弹窗点允许)。
2. 挂载成功后,同一页点 OpenOCD 卡片「启动」;**卡片显示 gdb 端口就绪**(3333)才算连上目标。
3. OpenOCD 起来后正常 `target remote :3333` 或用 IDE 接入。

> 注意:OpenOCD **只有真正握上目标芯片才会开 3333**。起不来多半是 SWD 线没接好,见排障表。

### 4.3 无线串口

串口桥监听 TCP 1234,首包发一行波特率即协商(如 `115200 E 1` → 波特率/校验/停止位;只发数字 `115200` 默认 8N1)。Python 例:

```python
import socket
s = socket.create_connection(("dap.local", 1234), timeout=3)
s.sendall(b"115200\n")          # 8N1;E 校验发 "115200 E 1\n"
print(s.recv(4096))
```

## 5. 排障表

### 5.1 工具报错码

| 码 | 含义 | 最常见原因 / 处理 |
| --- | --- | --- |
| 15 | 密码可能不对 | WPA2 密码错报的是 15 不是 202;注意大小写、全角半角 |
| 201 | 找不到这个 WiFi | 路由器只开了 5GHz(ESP32 只支持 2.4G);或信号太弱 |
| 202/204 | 认证被拒/握手超时 | 密码错,或路由器是 WPA3 专用(改成 WPA2/WPA3 混合) |
| 203 | 关联失败 | 路由器 MAC 白名单或连接数满 |
| 205 | 连接失败 | 信号差;把板子挪近路由器 |
| 404 | 固件不支持命令 | 固件太老,烧 v0.7.0+ |
| 405 | 设备还在启动 | 上电 20 秒内切模式会被拒,等一下再点 |
| 408 | 设备没响应 | USB 插错口(要 native USB/COM 口);线松;板子正在连网 |
| 409 | 当前模式做不了 | AP 模式不能扫描,先切回 STA |
| 423 | 设备忙 | 上一条命令还在跑,等几秒 |

### 5.2 连不上板子(网络侧)

| 症状 | 原因与处理 |
| --- | --- |
| `dap.local` 解析不出来 | ① 板子掉网了(绿灯还亮吗)② mDNS 缓存:板子换网后 Windows 可能缓存旧 IP,直接用板子 IP(看路由器后台)代替域名 ③ PC 和板子不在同一台路由器下 |
| IP 通但端口连不上 | 同上第 ③ 条最常见:**IP 前缀一样不等于同一个网**(例如两个路由器都开 192.168.0.x)。判别:PC 上 `arp -a` 里找不找得到板子 IP 的 MAC |
| 板子 IP 老是变 | 路由器 DHCP 正常行为。要么用 `dap.local`,要么在路由器后台给板子 MAC 绑定固定 IP |

### 5.3 调试链路不通

| 症状 | 原因与处理 |
| --- | --- |
| OpenOCD 起来但没有 3333 | 目标没握上手:① SWD 四根线(SWCLK/SWDIO/GND/3V3)**四根都要**,只接两根不共地必不通 ② 目标板要上电(调试器不供电给目标)③ 芯片型号选对没有 |
| usbip 挂载一直转 | 先看「调试接入」页的可达性检查;挂载前必须 3240 端口可达。挂载后**不要**在 usbip 上再跑 `list -r`,固件会卡死,拔电重启 |
| 读了半天文件被截断 | 无线读大文件约 4KB/s:512KB 目标固件 ≈ 2 分钟以上。工具/脚本的超时必须给到 5 分钟量级,否则文件悄悄断尾 |
| Keil 报 DAP 超时 | 先确认绿灯常亮;距离远信号差(-75dBm 以下)时下载会不稳,挪近点 |

### 5.4 串口/烧录的坑

| 症状 | 原因与处理 |
| --- | --- |
| 板子"假死"不响应 | **CH343 口(标 USB 的那个)插着线按了复位** → 进下载模式了。拔掉 CH343 线,只留 COM 口,再按板上 RST |
| 烧录失败/找不到口 | 固件烧录只走 **COM 口**(native USB);按住 BOOT 点 RST 进下载模式再烧 |
| 打开串口就全乱码/板子重启 | 正常现象:开 native USB 的 DTR/RTS 会踹板子复位(配网工具已做防踹处理;用别的串口终端时开完口按一下 RST) |
| 串口桥满屏 FF/00 | 波特率或线序不对:① 首包波特率要和目标板一致 ② TX/RX 交叉没接反 ③ 目标若是 RS-485 差分信号,需要转换,不能直连 |

## 6. 交付包里有什么

```
无线调试器/
├─ 无线调试器.exe          ← 双击这个(配网+调试接入统一入口)
├─ tools/
│  ├─ elaphureLink/        (Keil 插件,BSD-2,附源码获取说明)
│  ├─ openocd-elaphurelink/(GPL-2,独立进程,附 COPYING)
│  └─ usbip-win/           (GPL-2,独立进程,附 COPYING)
├─ firmware/               (固件 bin + 烧录说明,MIT)
├─ 快速上手.md              (本文的精简版)
└─ 许可与开源声明.txt
```

GPL 组件均为独立进程,不经你的项目代码链接,可放心商用闭源。

## 7. 恢复出厂

「已保存网络」页 →「恢复出厂设置」:清空所有已存 WiFi 并重启,回到固件内置的出厂网络。固件升级/换主人前建议先做这一步,免得把你的 WiFi 密码留在板子里。
